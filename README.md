# SC5002 Lab 1 — AI Fundamentals

This notebook compares Linear Regression and Ridge Regression using 1,000 sampled records from the California Housing dataset.

## Contents

- Data preparation and feature scaling
- Model evaluation using 5-fold cross-validation and R² scores
- Ridge experiments with alpha values of 0.1, 10, and 1000
- A chart comparing model performance

## How to run

Open the notebook in Google Colab or VS Code with the Jupyter extension.

For local use, install the required packages:

```bash
pip install numpy pandas matplotlib scikit-learn jupyter certifi
```

Select the Python kernel and run all cells in order. An internet connection is required for the first dataset download.
